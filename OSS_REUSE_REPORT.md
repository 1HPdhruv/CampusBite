## Scope of local additions

- Canonical checked subset: seven physical stations, two historical corridor references, nine station/line stops, four directed interchange edges. Alandur and Central memberships are independently checked against official CMRL map/chart, not imported from a community GTFS feed. No route adjacency, walking time, current full network or Yellow Line service claim is inferred.
- Four previously checked directed fare pairs retained; read-time local freshness window 30 days, explicit as-of dates, validity boundaries, invalid/future/historical/stale abstention, separate source URLs. No new prices were imported.
- Text agent returns deterministic source-qualified fare/lost-policy answers when those tools supply evidence; unverified/stale results cannot be replaced by a guessed model price. Demo disclosure is enforced on account tool responses.
- Live is opt-in (`GEMINI_LIVE_ENABLED=true`), single-use credentials, 30s start/90s expiry, 45s capture limit, only read tools, signed passenger-bound tool capability. Existing browser speech and text remain available.
- Tests use synthetic fixtures. Paired deterministic evidence/guard checks are not a claim of measured human Tamil quality or population-level LLM accuracy. Real microphone and device voice quality still need manual review.

Exact licenses were read before adapting source patterns. Only the two MIT patterns above are classified as source adaptations. All official source facts remain separately attributed in DATA_PROVENANCE.md and the existing source register.
